# My machine uptime stats

> This site was last updated at 2023-04-26T22:49:37+03:00

The following stats were collected via `uptimed` on all of my personal computers over many years and the output was generated by `guprecords`, the global uptime records stats analyser of mine.

> Uptimed is an uptime record daemon keeping track of the highest uptimes a computer system ever had. It uses the system boot time to keep sessions apart from each other.

[https://github.com/rpodgorny/uptimed](https://github.com/rpodgorny/uptimed)  
[https://codeberg.org/snonux/guprecords](https://codeberg.org/snonux/guprecords)
